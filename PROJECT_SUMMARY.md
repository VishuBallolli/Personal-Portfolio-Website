## 🎨 Theme Colors

The project uses a HSL-based color system that can be changed with a single variable:

```css
--hue-color: 250; /* Default: Blue-Purple */
```

**Available Themes:**
- Blue: 250 (default)
- Green: 142
- Purple: 280
- Pink: 340
- Orange: 14
- Red: 0

All theme colors automatically adjust for dark mode!
